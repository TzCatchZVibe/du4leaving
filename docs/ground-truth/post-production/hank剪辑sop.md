## Step 2 · 粗剪 (15 分钟)

### 严格按脚本分镜表切镜

每条脚本 (scripts-v2/) 都有"镜头分镜"表 · **照表切**。

### 必守 4 个节奏模板（按时长选 · 来自 visual-signature.md）

#### 30 秒 (典型主口播 / 反差金句)

```
0-3s    Hook 静止特写             → H 爆点
3-8s    人物中景 + 第一句台词       → R 共鸣
8-15s   慢推 + 字幕卡 + 一个 K 点    → K 知识
15-22s  慢动作双层质感             → 双层呼应
22-27s  反差金句 / 转折             → H + R
27-30s  CTA + 签名口播 + 包装定格   → CTA + 品牌音
```
切镜数 6-8 = 0.2-0.27 cut/s

#### 40 秒 (情境戏 / 节庆)
切镜数 8-10 = 0.2-0.25 cut/s

#### 50 秒 (Aurora 双人戏 / first-timer 反应) ← v2.1 后改 Freddy 独角
切镜数 10-14 = 0.2-0.28 cut/s

#### 25 秒 (ASMR · 5/8 拍的 7 条)
- 第一帧黑底字幕
- 撕膜"啵"声**第一帧就听到** (Hook 心理学)
- 静默 1.5-2s 必须留
- 几乎无 BGM

## Step 3 · 字幕 + 撕膜签名音效 + 静默 (10 分钟)

### 字幕签名 (visual-signature.md §1.4)

| 项 | 规则 |
|---|---|
| 字体 | **PP Neue Machina** (首选) / Söhne / Inter (备选) |
| 位置 | 屏幕中下偏上 1/3 (避开 TikTok 底部 UI) |
| 大小 | 单行最多 6 个英文词 (中文 8 字) |
| 颜色 | 主色 #FFFFFF + 1px 黑色描边 (任何背景清晰) |
| **关键词处理** | 1-2 个词放大 **1.3 倍** + 染 **#FF7B9C 粉色** |
| 入场 | 简单淡入 0.2s · **禁止弹跳/旋转** |
| 停留时间 | 每条字幕至少 **1.5 秒可读** |
| 全屏字幕卡 | 黑底白字 · 居中 · 停留 2 秒 · 每条**至多 1 张** |

### 全屏字幕卡 (35 条几乎都有 · KOZED Cozy 锚定)

格式固定：
```
[黑底全屏 · 居中]
KOZED — like 'cozy' but lazier.
                 ↑
            这词 1.3x + #FF7B9C 粉色
```

入场 0.2s 淡入 · 停留 2s · 出场 0.2s 淡出。

### 双人对话戏字幕 (#06 已 v2.1 改 Freddy 独角 · 不再适用)

如果未来 Aurora 改主意回归：
- Freddy 字幕**左对齐** · Aurora 字幕**右对齐**
- Freddy 字幕白底 · Aurora 字幕**米白底+粉色描边**
- Aurora 静默 5s 字幕显示 "..." 三秒

### 撕膜签名音效

每条结尾"Trust HappyGlobalChoice/Snacks"后留 **0.3 秒空** · 加 1 个独家撕膜采样音。

**音效来源**：5/8 周五 Frida 专门录的"啵"声 4-5 个最完美版本 (品牌签名音效库)。
- 5/2 剪 5/1 素材时 · Hank 用 5/1 当天 Frida 录的撕膜声做临时签名
- 5/9+ 剪 5/8 素材时 · 切换到 5/8 录的品牌签名音效库版本 (永久复用)

### ASMR 处理铁律 (#02 #07 #13 #18 #23 #29 #33 适用)

```
撕膜声原始录制 → 不要后期增强 (保持真实感)
+ 轻微低通滤波 (去掉 8kHz 以上的尖锐感)
+ 轻微混响 0.1-0.2s (剧场感)
+ 保留环境噪声 -25dB 底噪 (不是绝对静音)
```

### 静默节拍 (cozy 灵魂)

每条至少 **1 段 1-2 秒"什么都没说"**。

> 🚨 Hank 你最容易违反这条 · 请克制。**不要填满**。

## Step 4 · 调色 + 检查 4 关 (10 分钟)

### LUT 调色 (visual-signature.md §1.3)

#### Choice 主号 — 暖系 Cozy
```
主色：Cozy Cream      #F5EDE0
副色：Honest Brown    #8B6F4E
重点：KOZED Pink      #FF7B9C  (字幕关键词)
辅助：Honey Gold      #E5A04C  (黄昏光感)
```
LUT: 整体 +5 暖色温 / 黄色饱和度 +10 / 阴影 +5 棕褐 / **5-8% 胶片颗粒感** (Filmic Pro / FilmConvert)

#### Snacks 副号 — 暖系更暗 (5/8+ 拍的)
```
主色：Soft Beige      #E8D9C5  (比 Choice 浅)
副色：Espresso Dark   #3D2E1F  (低光区域)
重点：KOZED Pink      #FF7B9C
```
LUT 区别: Snacks 比 Choice **更暗一档** (更夜晚感、更私密)

### 🚨 四关检查 (这关挂了 = 阻止发布)

#### 第一关 · 合规红线 (任何一条触发 = 阻止发布)

- [ ] 没有提明胶来源 ("Bovine Gelatin" / "fish gelatin" 都不能说出来)
- [ ] 没有主动说 "Made in China" (包装上的字如入镜 OK 不刻意遮挡)
- [ ] 没有提保质期 (6 个月 / "lasts 6 months" 都不能说)
- [ ] 没有说 "natural / clean / all natural / organic"
- [ ] 没有儿童叙事 / 儿童入镜
- [ ] 没有说 "clearance / closeout / final sale / liquidation"

如果任何一条✗ → **删素材重剪 + ping Tom**

#### 第二关 · v2 双层质感呼应 (每条至少 1 种)

- [ ] visual_slowmo (慢动作展示外膜→内里)
- [ ] voiceover_line (Freddy 说"Outside layer first. Then the bite underneath.")
- [ ] subtitle_keyword (字幕"both layers"放大 + 粉色)
- [ ] audio_layered (撕膜声 + 咀嚼声分层)
- [ ] composition_topdown (俯拍展示糖果两层)
- [ ] rhythm_double_beat (剥外层 0-2s → 咬内层 2-4s 双拍点)

#### 第三关 · v2 Cozy 灵魂

- [ ] **Freddy 闭眼 1 秒**镜头保留 (每条至少 1 次)
- [ ] **静默 1-2 秒**保留 (Hank 不要填满)
- [ ] **Cozy 锚定**: 50%+ 视频前 15s 出现 "cozy" 字幕或台词

#### 第四关 · 视觉签名 10 题 (≥8 题"是" 达标)

详见 `hkrr/checklist-template.md` 第三关。10 题至少 8 题"是" = 达标 · 低于 8 = 重剪。

## 🎬 Hank 8 条剪辑铁律 (visual-signature.md §5)

1. **第一帧必须是"美到能截屏"的画面** — 决定划过来的人停不停下
2. **每个切点都要服务情感** — 不为节奏而切 · 为情感曲线而切 (Walter Murch 法则)
3. **保留 Freddy 的微停顿** — 不要把"嗯..."剪掉 · 这是 cozy 的人格
4. **撕膜"啵"声**必须在切镜瞬间或前后 0.1 秒内 — 视听同步
5. **字幕入场不要弹跳** — 简单淡入 · 1 帧 5%
6. **结尾包装定格至少 0.5 秒** — 让品牌锚定有时间
7. **不要堆字幕** — 一屏最多 1 行 · 全屏字幕卡每条至多 1 张
8. **每条至少 1 段 1-2 秒静默** — Hank 你最容易违反这条 · 请克制
