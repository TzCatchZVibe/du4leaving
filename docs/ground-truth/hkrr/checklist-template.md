# HKRR + 视觉签名通用自检清单

## 用法

每条视频 **拍后 (Frida)** + **剪后 (Hank)** 各过一遍 · 打勾。
- 视觉签名 10 题至少 8 题"是" = 达标 · 低于 8 = 重剪
- HKRR 4 维任何一维 <80 = 重写/重剪
- 合规红线 6 条任意一条违反 = **阻止发布**

---

## 第一关 · 合规红线 (任何一条触发 = 阻止发布)

- [ ] **没有提明胶来源**（"Bovine Gelatin" / "牛源" / "fish gelatin" 都不能说）
- [ ] **没有主动说 Made in China**（包装上的字如入镜 OK 不刻意遮挡）
- [ ] **没有提保质期**（6 个月 / "lasts 6 months" 都不能说）
- [ ] **没有说 natural / clean / all natural / organic**
- [ ] **没有儿童叙事**（kid-friendly / great for kids / 喂孩子等）
- [ ] **没有说 clearance / closeout / final sale / liquidation**

如果任何一条✗ → **阻止发布** + 重写/重剪

---

## 第二关 · HKRR 4 维 (任何一维 <80 = 不达标)

### H 快乐 (Happiness) ≥80
- [ ] 神经科学 4 通路至少触发 2 个 (dopamine / endorphin / oxytocin / serotonin)
- [ ] Hook 0-3s 有反差感 / 好奇心 / 视觉冲击之一
- [ ] 至少 1 个 Aha 时刻（金句 / 反差转折 / Cozy 命名梗 等）

### K 知识 (Knowledge) ≥80
- [ ] 至少 1 条 L3+ 知识池信息（来自 `knowledge-pool-v1.0.md`）
- [ ] 信息呈现自然 · 不像在念说明书
- [ ] 知识与情感连接（不是冷冰冰的事实）

### R 共鸣 (Resonance) ≥80
- [ ] **镜像神经元 time + location + action 三元组**齐全（如 "Friday 8pm + in my truck + peeling candy alone"）
- [ ] 五感至少触发 3 个（视/听/触/味/嗅）
- [ ] 场景具体到能"看见自己"

### R 节奏 (Rhythm) ≥80
- [ ] 切镜数符合时长（30s = 6-8 cuts · 40s = 8-10 cuts · 50s = 10-14 cuts）
- [ ] **Walter Murch 优先级**: emotion > story > rhythm > eye-trace > 2D > 3D
- [ ] 至少 1 段 1-2 秒静默
- [ ] 撕膜"啵"声在切镜瞬间或前后 0.1 秒

---

## 第三关 · 视觉签名 10 题 (≥8 题"是" 达标)

- [ ] 1. 第一帧能截屏当封面吗？
- [ ] 2. 60% 镜头完全静止吗？
- [ ] 3. 至少 1 次缓慢推进吗？
- [ ] 4. 黄金时段 / 暖光控制好了吗？(3500-5500K · 不要冷色)
- [ ] 5. **🆕 v2 双层质感**有清晰展示吗？(visual_slowmo / voiceover_line / subtitle_keyword / audio_layered / composition_topdown / rhythm_double_beat 至少 1 种)
- [ ] 6. 撕膜"啵"声听得清吗？
- [ ] 7. 字幕在中下偏上 1/3 位置吗？
- [ ] 8. **🆕 v2 关键词放大 + 粉色 #FF7B9C 高亮**做了吗？
- [ ] 9. 至少 1 段 1-2 秒静默吗？
- [ ] 10. 结尾签名口播 + 包装定格 + 品牌音齐了吗？

10 题 ≥8 = 达标

---

## 第四关 · v2 新增专项 (Cozy 灵魂 + 双层质感)

- [ ] **🆕 Freddy 闭眼 1 秒签名**（每条至少 1 次 cozy 享受瞬间）
- [ ] **🆕 Cozy 锚定**: 50%+ 视频前 15 秒出现 "cozy" 字幕或台词
- [ ] **🆕 Cozy 浓度** ≥70（个别条目 ≥60 + 其他维度补足）
- [ ] **🆕 双层质感呼应**至少 1 种方式
- [ ] **🆕 Aurora 字幕签名**（如有 Aurora 出镜）：左右对位 + 颜色微差 + 静默 "..." 字幕

## 第五关 · Aurora 双人戏专项 (#06 #16 #25 适用)

- [ ] Freddy 字幕**左对齐** · Aurora 字幕**右对齐**
- [ ] Freddy 字幕白底 · Aurora 字幕**米白底+粉色描边**
- [ ] **#25 五秒静默**保留了吗？(一镜到底不能切)
- [ ] Aurora 同色系视觉延续（米白/米色/浅灰针织 + 同款耳环跨 3 条）

## 第六关 · ASMR 专项 (#02 #07 #13 #18 #23 #29 #33 适用)

- [ ] 撕膜"啵"声**第一帧**就听到了吗？
- [ ] 240fps 真慢动作（不是后期变速）？
- [ ] 双层质感视觉证据（外膜分离→裸糖）清晰吗？
- [ ] 1.5-2 秒静默保留？
- [ ] 没有 BGM / 极简 BGM？
- [ ] 没有过度 ASMR 雷区（呻吟 / 软嗓 / 过度暗示）？

---

## 第七关 · 防御视频专项 (#04 #09 #12 #17 #22 #30 适用)

- [ ] 诚实大叔人设保持？(不夸张 / 不嘲讽 / "Respectfully")
