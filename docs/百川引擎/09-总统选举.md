## §2 数学骨架

### 2.1 民调聚合

```
poll-aggregation · Bayesian 加权
  权重 = 1 / (sample_size × pollster_house_effect_var)

加州 / 纽约的州长选举 ·
  20 个民调 → 加权平均 + std
  P_aggregate = N((vote_share - 0.5) / sigma)
  sigma 选举前 30 天 ≈ 4pp · 选举前 7 天 ≈ 2pp
```

### 2.2 Polymarket 鲸鱼跟单

```
全球大选 · Polymarket 活跃度高
  · Top 10 钱包押什么 · 你跟
  · 必须 · wr ≥ 55% · 历史 ≥ 30 单
  
跟单数学 · 对每个市场 ·
  weighted_direction = sum over qualified whales: w_i × direction_i × stake_i
  P_whale_consensus = sigmoid(weighted_direction)
  
跟单延迟 ≈ 5-15 分钟 (whale 加仓后 cron 检测)
```

### 2.3 历史先例 (Cook PVI)

```
Cook Partisan Voter Index · 美国每选区历史投票偏向
对未表态选区 · 用 PVI 当 baseline
PVI D+5 → P(D 赢) ≈ 0.65 (默认)
```
