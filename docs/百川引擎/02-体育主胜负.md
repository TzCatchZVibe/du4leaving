## §1 元逻辑

```
本质 · 队伍实力评分 (Elo / Glicko / Massey-Colley) + 市场反公众
不是真预测对手 · 是
  · 用统一评分系统给每队定位 (Elo)
  · 找 Kalshi 价格 vs Elo 的偏差 (model edge)
```

## §2 数学骨架

### 2.1 Elo 评分 (主)

```
两队对战 · A (评分 R_A) vs B (评分 R_B)

期望胜率 ·
  E_A = 1 / (1 + 10^((R_B - R_A) / 400))

赛后更新 ·
  R_A' = R_A + K × (S_A - E_A)
    S_A · 实际结果 (1 赢 / 0.5 平 / 0 输)
    K   · 学习率 · NBA 用 20 · 足球 30 · 电竞 24

主场加成 (各项目不同) ·
  NBA · +100 Elo
  NFL · +50
  MLB · +20
  Soccer · +60
  Esports · 0 (除部分线下赛)
```

### 2.2 Glicko-2 (升级版 · 含信心度)

```
每队不仅有评分 · 还有 RD (rating deviation · 不确定性)
新队 / 久不打 RD 大 · 多打几场 RD 小
预测时 · 高 RD 队 → 给更宽 P 区间

适用 · 赛季初 / 球员伤退后队伍重组 · Elo 失灵期
```

### 2.3 反公众投注 (反 chalk)

```
统计学事实 (40+ 年体育博彩数据) ·
  当 < 30% 投注押在 underdog 时 · underdog 长期 wr ≈ 51-53%
  当 > 70% 投注押在 favorite 时 · favorite 长期 wr ≈ 47-49%
  
原因 · 群众喜押热门 → 热门隐含价虚高 → 长期 EV 负

应用 · Kalshi 不公开投注比例 · 但
  · vol 流量信号 (买 yes 流入 > 买 no 流入 = 公众压 yes)
  · 大单买入方向 (鲸鱼) 反着的
```

## §9 代码骨架

```typescript
// src/lib/xiapan/elo.ts
export interface EloRecord {
  team: string;
  rating: number;
  rd?: number;       // Glicko-2
  last_updated: string;
}

const K_BY_SPORT: Record<string, number> = {
  nba: 20, nfl: 25, mlb: 18, nhl: 22, soccer: 30, esports: 24,
};

const HOME_BONUS: Record<string, number> = {
  nba: 100, nfl: 50, mlb: 20, soccer: 60, esports: 0, nhl: 50,
};

export function expectedScore(R_a: number, R_b: number, sport: string, isHome: boolean): number {
  const home = isHome ? HOME_BONUS[sport] ?? 0 : -(HOME_BONUS[sport] ?? 0);
  return 1 / (1 + Math.pow(10, (R_b - R_a - home) / 400));
}

export function updateRating(R: number, expected: number, actual: number, sport: string): number {
  const K = K_BY_SPORT[sport] ?? 20;
  return R + K * (actual - expected);
}

// 训练 · 一次性跑历史 · 输出 elo-train-YYYY-MM.json
export async function trainEloFromHistory(games: Array<{
  date: string; home: string; away: string; home_won: 0 | 0.5 | 1;
  sport: string;
}>): Promise<Record<string, EloRecord>> {
  const ratings: Record<string, number> = {};
  for (const g of games) {
    const rh = ratings[g.home] ?? 1500;
    const ra = ratings[g.away] ?? 1500;
    const eh = expectedScore(rh, ra, g.sport, true);
    ratings[g.home] = updateRating(rh, eh, g.home_won, g.sport);
    ratings[g.away] = updateRating(ra, 1 - eh, 1 - g.home_won, g.sport);
  }
  // 转 records
  return Object.fromEntries(Object.entries(ratings).map(([k, v]) => [k, {
    team: k, rating: v, last_updated: new Date().toISOString(),
  }]));
}
```
