## §4 关键架构决策

```
1. 信号 confidence 默认 0.51-0.85 严格剪
   过低 (<0.51) · 比随机差 · 退役
   过高 (>0.85) · 假高 · 真信号也不会这么准
   防止过拟合 · 强制 fusion 中性化

2. n_active ≥ 2 是 stable 桶硬要求
   单源永远不下 (即使是 BS · 因为 spot/vol 估错也可能错)
   convex 桶 ≥ 1 (long-shot 允许孤注)

3. 信号方向冲突 = 失效
   两个独立信源指相反方向 = 信息冲突 · edge 失效 · 跳过
   防止"互相打架"的伪信号

4. weights 自适应 · 每周 Brier 调
   Brier ≤ 0.18 → 1.5x · 退役阈 0.40
   不需要手调 · 自学的系统

5. P0 红线 (本金 × 0.85) 
   防灾难 · 系统失控 · 自动 stop
   人工 /resume 才解锁

6. 月底 hurdle 8% + 阶梯 cashout
   v1 你提 / v2 上网研究后迭代
   PE waterfall · Kahneman disposition · 多重防御

7. 7 路信号源全 cron 自动跑
   你不参与日常 · 月底看 /pools 报表 + Telegram alert
```
