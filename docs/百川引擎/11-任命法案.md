> Tier 3 · 实施成本 4 周 · 预期 wr 52-55% · 月 ROI 1-2%

## §1 元逻辑

```
本质 · "X 法案是否本届通过" · 长事件 · 极端二元
       国会数据 (vote count) 公开 · 但叙事性强 · LLM 难
跟单为主 · 不自建模型
  · 跟 Polymarket 政论鲸鱼
  · 跟 GovTrack / FiscalNote 等专业平台 (有时付费)
  · 用历史基率作为 prior (法案过率 ≈ 4% 提交 / 30% 委员会过 / 80% 投票通过)
```

## §2 数学骨架

```
P_pass = base_rate(stage) × narrative_adjust

stage 各级别基率 ·
  introduced 提交 → 4% 通过
  committee 进入 → 30%
  floor vote schedule → 80%
  House passed only → 50% (待参院)
  both chambers → 95% (待签字)

narrative_adjust · LLM 解析新闻 · 主导党推 +5pp / 反对党阻 -8pp
```
