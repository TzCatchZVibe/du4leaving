## §2 数学骨架

### 2.1 NWS / NDFD 数字预报数据库

```
National Digital Forecast Database (NDFD)
  · 7 天逐 1-3 小时 · 全美格点温度/湿度/降水/风
  · 公开免费 GRIB2 / XML / JSON
  · 每 6 小时更新

API · weather.gov/forecast/
  
对单点 (e.g. NYC LaGuardia) ·
  GET https://api.weather.gov/points/40.7766,-73.8740/forecast
  返回逐 1h · temp / rain / wind 等
```

### 2.2 ensemble 概率提取

```
GEFS (Global Ensemble Forecast System) · 31 成员
  每成员独立预测 · ensemble = 31 个未来轨迹
  
对"NYC 周五最高温 ≥ 75°F" ·
  count = 多少成员预测 max ≥ 75
  P_ensemble = count / 31

精度 · NOAA 公开 · 7 天预报 RMSE ≈ 2-3°F
       3 天 RMSE ≈ 1°F
       1 天 RMSE ≈ 0.5°F
```

### 2.3 历史校准

```
NWS / GEFS 在长期统计上略有 bias ·
  · 夏天高温 · 略偏低 (实际更热)
  · 冬天低温 · 略偏高 (实际更冷)
  · 降水 · 整体偏低估

校准函数 ·
  P_calibrated = sigmoid(α × (P_ensemble - β) + γ)
  α / β / γ 通过历史 1 年校准

简化 (无校准) · P_ensemble 直接用也比 Kalshi 散户准
```

## §9 代码骨架

```typescript
// src/lib/xiapan/weather.ts
const NWS_BASE = 'https://api.weather.gov';

const KALSHI_CITY_MAP: Record<string, [number, number]> = {
  NYC: [40.7128, -74.0060],
  LA:  [34.0522, -118.2437],
  CHI: [41.8781, -87.6298],
  // ...
};

export async function getNWSForecast(lat: number, lng: number) {
  const meta = await fetch(`${NWS_BASE}/points/${lat},${lng}`).then(r => r.json());
  const fcUrl = meta.properties.forecast;
  const fc = await fetch(fcUrl).then(r => r.json());
  return fc.properties.periods;  // 逐期预报
}

export interface KalshiWeatherTicker {
  city: string;
  type: 'high' | 'low' | 'rain';
  date: string;          // ISO date
  threshold: number;     // °F or inches
}

export function parseKxweatherTicker(ticker: string): KalshiWeatherTicker | null {
  // KXHIGHNYC-26MAY02-T75
  const m = ticker.match(/KX(HIGH|LOW|RAIN)([A-Z]+)-(\d{2}[A-Z]+\d{2})-T(\d+)/);
  if (!m) return null;
  return {
    type: m[1].toLowerCase() as 'high' | 'low' | 'rain',
    city: m[2],
    date: parseKalshiDate(m[3]),
    threshold: parseInt(m[4]),
  };
}

export async function fairPWeather(t: KalshiWeatherTicker): Promise<{ P: number; raw_forecast: number; sigma: number }> {
  const [lat, lng] = KALSHI_CITY_MAP[t.city] ?? [0, 0];
  const periods = await getNWSForecast(lat, lng);
  // 找目标日期那天 · 取 max / min / sum precipitation
  const day = periods.filter(p => p.startTime.startsWith(t.date));
  let raw_forecast: number;
  if (t.type === 'high') raw_forecast = Math.max(...day.map(p => p.temperature));
  else if (t.type === 'low') raw_forecast = Math.min(...day.map(p => p.temperature));
  else raw_forecast = day.reduce((s, p) => s + (p.probabilityOfPrecipitation?.value ?? 0), 0) / day.length;
  
  // 距到期天数 · 决定 σ
  const daysOut = (new Date(t.date).getTime() - Date.now()) / 86400000;
  const sigma = 0.5 + daysOut * 0.4;  // 1d=0.9 / 7d=3.3
  
  // P(actual ≥ threshold) = 1 - Φ((threshold - forecast) / σ)
  const z = (t.threshold - raw_forecast) / sigma;
  const P = 1 - normalCDF(z);
  return { P, raw_forecast, sigma };
}
```
