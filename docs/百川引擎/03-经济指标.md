## §2 数学骨架 · 期货反推 P

### 2.1 Fed Funds Futures → P(rate)

```
CME 30-Day Fed Funds Futures (代码 ZQ)
  价格 = 100 - 隐含月平均 Fed Funds rate

例 · Q1 月 ZQM5 价 = 95.625
   隐含月均 rate = 4.375%
   当前 rate = 4.50%

   假设月内 N 天会议日 ·
   P(降 25bp) = (4.50 - 4.375) / (会议日比例 × 0.25) 
              ≈ 50% 隐含降息
```

```
Kalshi · "5月 FOMC 降 25bp" yes 65¢
你算 · 期货隐含 50%
edge · -15pp · 卖 yes (买 no @ 35¢)
```

### 2.2 CPI nowcast (Cleveland Fed)

```
Cleveland Fed Inflation Nowcasting
  · 实时模型预测下次 CPI
  · 公开免费 · 每周更新
  · https://www.clevelandfed.org/indicators-and-data/inflation-nowcasting

P(CPI ≥ X%) = N((nowcast - X) / σ)
  σ ≈ 0.15pp (历史 nowcast 误差)
```

### 2.3 Jobs (NFP) 一致预期

```
Bloomberg consensus / Reuters poll · 公开摘要
分析师中位数 · 标准差给出
  P(NFP ≥ X) = 1 - Φ((X - median) / std)
  
历史 std 约 65k jobs · 中位数到 +60k 涨幅 P ≈ 18%
```

### 2.4 GDP 季度

```
Atlanta Fed GDPNow · 实时模型
  https://www.atlantafed.org/cqer/research/gdpnow
P(GDP ≥ X%) = 类似公式
  σ_GDPNow ≈ 0.5pp
```
