## 元方法论 · 我们对每个品类问的同一组问题

每进入一个新品类前 · 必须回答这 8 个问题。任何答 ✗ 的品类都退到次优先级。

```
1. 这个品类有真理基准 (ground truth) 可拉吗?
   ✓ BTC 现价 / 体育终场比分 / FDA 批文
   ✗ "气氛"·"动力" 这种概念

2. 有数学公式能算公允价吗?
   ✓ Black-Scholes / Elo / Bayes / 历史频率
   ✗ "感觉"

3. 数据源是公开免费 / 低成本的吗?
   ✓ Coinbase API / NWS / SEC EDGAR
   ✗ Bloomberg / IBES (机构付费)

4. 单事件持续时间 < 7 天吗?
   ✓ 短窗 = 反馈快 = 学习快
   ✗ 长事件 (大选 18 月) 学习慢

5. AI agent 能 8B 跑还是必须 405B?
   ✓ 数学 / 状态机 → 8B 够
   ✗ 复杂叙事 / 翻译外语新闻 → 405B 必须

6. 流动性 vol_24 ≥ $500?
   ✓ 主流分类
   ✗ 冷门 (执行打折)

7. 是否有不可独立替代的"质性信息"?
   ✓ 体育伤情 / 政论说漏嘴 → 大数据收集 + LLM 解析能拼
   ✗ 内幕 (球员家事 / 法官私心) → 没法搞

8. 抄机构成本 vs 自建模型成本差多少?
   ✓ 跟 YN Signals / FiveThirtyEight 抄 < 自建
   ✗ "我能做出比 Polymarket 鲸鱼准的模型" → 99% 不能
```

... (12 路全)

─────────────────────
fusion.ts · log-odds Bayesian 合
risk.ts   · Kelly + drawdown 缩
gates.ts  · 5 条决策门 (edge / vol / spread / orth / drawdown)

输出端 (统一)
─────────────────────

lessons.jsonl · 每单写
Brier 校准 · 50 单重权
Deflated Sharpe · 200 单退役坏 signal
