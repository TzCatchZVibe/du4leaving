# 08 · 体育实时 · In-Game Win Probability

> Tier 2 · 实施成本 4 周 · 预期 wr 55-62% · 月 ROI 3-7% · 高频但需 1s 反应

## §1 元逻辑

```
本质 · 比赛进行中 · 比分/时间/状态 → 当前 win probability
       公开模型 (538/ESPN) 给 P_in_game · Kalshi live 价 vs 之 · 套利
不是赛前 · 是
  · 第 1 节后 · 数据已多 · 模型准
  · Kalshi live 价跟散户情绪 · 容易过激
  · 反向押"过激方向" 是 alpha
```

## §2 数学骨架

### 2.1 In-Game Win Probability 模型

```
NBA · 538 模型公开 / ESPN 模型 (HTML 抓)
  输入 · 当前比分差 + 剩余时间 + 主客场
  输出 · home_team P(win)

NFL · ESPN GameCast 提供 win probability (实时 HTML)
  EPA-based (Expected Points Added)
  
Soccer · xG (expected goals) 实时
  · understat.com 提供 historical
  · 实时较难 · 需要 Opta 数据 (付费)
```

### 2.2 反过激

```
Kalshi 比赛中价格 ·
  比分大幅领先时 · favorite price 飙到 90%+
  历史显示 · 90%+ favorite 实际 wr 88% (多 1-2pp 价虚)
  
反向 · 价 ≥ 92% 的 favorite · 押 under-dog · 期望 +EV
但 stake 必须小 (输大概率 · 赢小概率)
```

### 2.3 节奏 / pace 信号

```
NBA 球队节奏数据 (possessions per 48 min)
高节奏队 + 高节奏对手 · 总分 over 概率高
Kalshi total points 市场套利
```

## §7 期望 EV

```
单赛季 NBA · 80 场 × 30 价格点 × 60% 触发 ≈ 1500 触发
但执行难度高 · stake 必小 ($2-3)
wr 55% · per trade EV ≈ +$0.10
扣抽水 = +$0.05

月 EV (10 单/天 × 30) = +$15 · 4%/月
但实际能跑通的 ≤ 这个 · 因为执行延迟
```

## §8 失败模式

```
1. 数据延迟 5-30s · 价格已动
   防 · websocket 直连 · 不要 HTTP polling
   或 · 仅做 1 节后开始 · 数据较稳

2. Kalshi 突然停盘 (受伤 / 推迟)
   防 · 监听 Kalshi market_status · 自动撤单
```
