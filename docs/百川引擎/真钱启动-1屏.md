# 真钱启动 · 1 屏 (15 分钟)

## 起步参数

```
P0 = $50 (起步本金 · 不是 $400)
单笔 ≤ $1   (硬写死 · 改不了)
日新单 ≤ 5
日新钱 ≤ $5  (最坏单日亏 $5 = 10% drawdown · 不破本金)
```

## 5 步

```
1️⃣  Kalshi 网站 → Settings → API
   · 创 RSA key pair
   · 下载私钥 .pem 到本地

2️⃣  上传 .pem 到 mini ·
   scp ~/Downloads/kalshi.pem mini:~/.kalshi/private.pem
   ssh mini 'chmod 600 ~/.kalshi/private.pem'

3️⃣  ssh mini · 编辑 .env.local 加 3 行 ·
   LIVE_TRADING=true
   KALSHI_API_KEY_ID=<你的 UUID>
   KALSHI_PRIVATE_KEY_PATH=/Users/laoxia/.kalshi/private.pem

4️⃣  重启 next-dev ·
   ssh mini 'launchctl unload ~/Library/LaunchAgents/com.tz.du4.next-dev.plist; sleep 2; launchctl load -w ~/Library/LaunchAgents/com.tz.du4.next-dev.plist'

5️⃣  Telegram 重置 pools 到 $50 ·
   /pools_reset 50
   (清 paper 历史 · 用 $50 真钱起 · lessons.jsonl 留供回看)

完成 · Telegram /钱 应显示 "🔴 真钱"
```

## 验证

```
/钱   显示 "🔴 真钱 ✓" + 余额
/事   显示 "✓ Kalshi RSA 已绑"
```

## 出问题

```
回 paper · ssh mini · 改 .env.local · LIVE_TRADING=false
重启 next-dev · /钱 显示 "📋 paper" 即恢复
```
