# 15 · TZ 两池模型 v2 · House Money + Hurdle + 阶梯 cashout

> 撰写: 2026-05-01 · v1 (TZ 提) → v2 (蒸馏 12 维学术研究后迭代)
> 评分 v1 6.5/10 (散户 sophisticated) → v2 8.5/10 (prop firm 标准)

## §1 一句话

```
本金 P0 永远不动 · 起步 90/10 平行哑铃 ·
S 池 (稳赚) 通过 hurdle 8% 才"奖励"溢出给 C 池 ·
C 池 (以小搏大) 大胜阶梯 cashout (30/50/70) ·
drawdown 熔断 + ¼ Kelly 单笔上限 + 税务感知
```

## §2 v1 → v2 · 5 处迭代依据

| 迭代 | v1 (你 · sequential) | v2 (学术 + 实践) | 学术依据 |
|---|---|---|---|
| 起步分配 | P0 100% → S | 90% → S · 10% → C (parallel) | Taleb · Antifragile |
| S 转 C 规则 | S 净赚 100% 转 C | S 超 hurdle 8% 才转 | PE waterfall · preferred return |
| Cashout 比例 | 50% / 50% (固定) | 阶梯 30/50/70 (按规模) | Disposition Effect · Kahneman |
| 单笔 size cap | C × 5% | min(C×5%, ¼ Kelly, $5) | MacLean/Thorp · LTCM 教训 |
| Drawdown 熔断 | 没明确 | S -5% 暂停 C / S -15% 全停 | Brown / Risk parity |

```
│                                                          │
│   月初 S = $S_start                                       │
│   月末 S = $S_end                                         │
│   月化收益率 R = (S_end - S_start) / S_start              │
│                                                          │
│   if R < 0.667% (= 8%/12 month):                         │

│                                                          │
│   else (R ≥ 8%/年):                                       │
│     hurdle_amount = S_start × 8% / 12 = 0.667% × S_start │
│     transfer_to_C = (S_end - S_start) - hurdle_amount    │
│     S 调回 = S_start + hurdle_amount (复利基)             │
│     C += transfer_to_C                                   │
└──────────────────────────────────────────────────────────┘
                          │
                          ↓ C 池 net_gain check
┌──────────────────────────────────────────────────────────┐

│                                                          │
│   net_gain = C_current - C_initial - all_deposits        │
│                                                          │
│   if net_gain < $50:                                     │
│     不动 · 累积 · 等达 $50                                │
│                                                          │
│   if $50 ≤ net_gain < $300:                              │
│     30% cashout (实际税后 $0.63 × 30 = ~$19)              │
│     70% 回 S 池 (复利再投)                                │
│                                                          │
│   if $300 ≤ net_gain < $1000:                            │
│     50% / 50%                                            │
│                                                          │
│   if net_gain ≥ $1000:                                   │
│     70% cashout (大胜锁利)                                │
│     30% 回 S 池                                          │
│                                                          │
│   重置 C_initial = C_current_after_distribution          │
└──────────────────────────────────────────────────────────┘
                          │
                          ↓ drawdown 熔断 (实时检)
┌──────────────────────────────────────────────────────────┐
│ S 池 -5% 月内 drawdown · 暂停 C 池 1 月 · 审 edge        │
│ S 池 -15% 月内 · 全停 1 周 · 复盘                         │

└──────────────────────────────────────────────────────────┘
```

## §7 不做的事 (反指引)

