# 05 · 公司财报 · Earnings Beat / Revenue / Guidance

> Tier 1 · 实施成本 2 周 · 预期 wr 55-60% · 月 ROI 3-5% · 季度集中

## §1 元逻辑

```
本质 · "X 公司 Q3 EPS 是否 beat" · 二元市场
       一致预期 (analyst consensus) 是 prior · whisper number 是修正
       公司内部信号 (insider trading / 招聘速度) 是 alpha
不是研究公司 · 是
  · 套用一致预期 vs Kalshi 当前价
  · 用 whisper number (买方/卖方 真预期) 修正
  · 历史 surprise 习惯调
```

## §2 数学骨架

### 2.1 一致预期 + Surprise

```
analyst_consensus · 公开 (Yahoo Finance · Zacks)
whisper · 买方 sell-side 私下高于公开预期
historical surprise · 公司过去 N 季 actual - consensus

P(beat) = base_rate + surprise_history_offset + whisper_adjust

base_rate 大型公司平均 ≈ 60% (historical · 大盘股有 beat 倾向)
            小型 ≈ 50%
whisper_adjust · whisper > consensus 时加 5pp · 反之 -5pp
```

### 2.2 短期信号 (盘后 1 分钟)

```
财报盘后 release · 4:05 ET 数据出
Kalshi 几分钟内调整慢 · 散户更慢
你 · 数据出 → 立即解析 → 1-2 分钟内下单

要求 · 极快的 cron (10s) + 解析机制
具体 · SEC EDGAR Atom feed · 8-K filing 实时
```

### 2.3 招聘速度 / 内部信号

```
招聘信息减少 / 关键岗 (CFO 离任) → 财报弱
LinkedIn 数据 + 公司主页招聘列表 → AI 解析趋势
窗口 · 财报前 2-4 周
```

## §4 信号子源

### 4.1 Consensus 偏离

```
P_consensus = 0.60 (大型 base) 
              + 0.05 × (whisper - consensus 同向)
              + 0.04 × (近 4 季 average surprise > 0)
              
edge_pp = (P_consensus - kalshi_yes_ask/100) × 100
```

### 4.2 Earnings Drift (盘后短期)

```
EPS release 后 · 股价立即 ±X% · Kalshi 价格滞后 5-30 秒
若股价飙 + Kalshi yes 仍便宜 · 速买
若股价跌 + Kalshi yes 仍贵 · 速卖

需要 · realtime price (Yahoo / Robinhood) + 1-2s ms 反应
```

### 4.3 Pre-earnings 招聘速度

```
公司财报前 4 周 · LinkedIn 公开招聘数 vs 同期去年
增 > 20% → 业务好 → 利好 EPS · +3-5pp
减 > 20% → 紧缩 → -3-5pp
```
