## 4 · 房间空间化 · 8 个内部房间细化设计

### 00 大堂 (Dashboard) · "今天工会有什么动静"
```
- 顶 · 时间 + 天气 + 公会公告 (TZ 留言)
- 中 · 今日任务卡 (3-5 张) · 每张是一个 NPC 任务
- 右 · 公会成员动态 (Frida 刚发布 / Hank 在剪)
- 底 · 进入其他房间的传送门 grid
```

### 01 战图厅 (Intel) · ★ 已落地最多
```
- 全屏地图 · 飞机/海洋/晨昏 在动 (鸟瞰世界)
- LiveFeed 实时事件 (右下)
- 聚焦模式 = 进入"战略凝视"
- 升级方向 · 加 NPC 评论 (虾家族对世界局势插话)
```

### 02 仓库 (Library) · 装备/道具栏
```
- 素材分 6 类 · 像 RPG 装备槽 (头/身/手/腿/武器/饰品 → 视频/图/音/字/链接/灵感)
- 每件素材 · 有 rarity (common/rare/legendary)
- 拖拽到工坊 · 触发"打造合成"
- "今日新获 · 装备" 入场动画
```

### 03 图书馆 (Learn) · 知识塔
```
- 像极乐迪斯科思维橱柜 · 每读一本 · 解锁新对话选项
- 已读书架立体感 · 摆放可视化
- 阅读时 · 旁白 narrator 风格 · 不是普通 markdown
```

### 04 议事厅 (Chat) · 公会聊天
```
- 文字聊天 · 但带"NPC 反应" (虾家族 react emoji)
- 重要决议 · 弹"羊皮纸"卷轴而非普通弹窗
- 多人语音 · 加入像进入公会语音房
```

### 05 工坊 (Recipe) · 制作菜谱
```
- 菜谱 = 内容生产配方
- 每个步骤是一个工序 · 像炼金术
- 完成 · 出锅动效 + sfx
- 失败 · "还需练习" + 提示
```

### 06 邮政厅 (Publish) · 信使任务
```
- 每条要发布的内容 = 一封要寄出的信
- 选择平台 = 选择信使 (TikTok = 飞鸽 / X = 闪电邮 / 公众号 = 飞书雕)
- 发出去 · 信使飞向地图上对应平台坐标
- 数据回流 · 信使捎回 (回邮)
```

### 07 监控塔 (Monitor) · 数据塔
```
- 视角 · 站在塔顶俯瞰整个公会数据
- 数字不是冰冷 · 是"公会商业活力"图谱
- 上升 · 蓝色光晕 / 下降 · 暖橘 (不是红 · 不刺眼)
```

## 10 · 元宇宙方向 (TZ 追加 2026-04-24)

### 元宇宙 vs 普通网游 · 关键区别

```
普通网游            元宇宙
────────────       ────────────────
玩家离线 · 暂停    玩家离线 · 世界仍运转
角色固定 · 选职业   角色无限 · 玩家定义自己
经济封闭            经济开放 · 资产可流转
空间分页            空间持久 · 跨设备一致
官方主导内容        玩家生成 (UGC) 与官方共生
```

### CatchZVibe 元宇宙化 · 6 步

```
步 1 · 持久状态 (容易 · 已部分实现)
   - intel 实时数据 (飞机/海/事件) 自然持久 · 离线仍在更新
   - dashboard 公告/任务 持久存在
   - chat 历史持久

步 2 · 化身 (avatar) (中等)
   - 玩家 handle + 称号 + 自定义 SVG 头像 (可拼装)
   - 头像在 sidebar / dashboard 出现
   - 进入房间 · 头像出现在该房间右侧 (在线指示)

步 3 · 跨房间存在感 (中等)
   - 我在 intel · 别人能在 dashboard 看到 "TZ 正在战图厅"
   - 多人在线浮标 · 公会大门外的"今日活跃 N 人"
   - WebSocket presence (用 Supabase Realtime)

步 4 · 经济系统 (复杂)
   - 素材 = 道具 · 有稀有度
   - 任务 = 奖励 (但不是钱 · 是"创作动力点" · 软性虚拟资产)
   - 工坊配方 · 输入素材 · 输出内容 · 像合成
   - 不引入区块链 · 但保留"资产可视" 的元宇宙感

步 5 · UGC (远期)
   - 玩家可自定义自己的"摄影师工作室房间布局"
   - 公开访问者可"参观"某摄影师房间
   - 私人收藏 · 公开展览 · 像 Decentraland gallery

步 6 · 跨设备 + VR/AR ready (未来)
   - 移动版本 · 同账号无缝
   - 关键房间 (战图厅) · 适配 Vision Pro / Quest 立体浏览
   - 公会语音 spatialized · 离 NPC 远近声音不同
```

### 元宇宙在我们语境里 · 不是

```
✗ 不是 · 区块链 / NFT / 加密货币
✗ 不是 · 必须 3D 引擎 (Unity/Unreal · 太重)
✗ 不是 · 必须 VR (太小众)
✗ 不是 · 玩家无限多 (我们是公会 · 几十几百足够)

✓ 是 · 持久共享空间感 · 离开后仍存在
✓ 是 · 化身可见 · 我能看见你你能看见我
✓ 是 · 角色自由定义 · 不被职业框死
✓ 是 · 跨设备一致 · 进得去就是回家
```

### 落地优先级

```
最快 ·  化身头像 + 在线状态 + 跨房间 presence
中期 ·  公会大门外多人浮标 (访客也看得见我们活跃)
远期 ·  资产经济 + UGC 房间布局
最远 ·  VR 适配 (战图厅 立体地球)
```
