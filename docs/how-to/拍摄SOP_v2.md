## 0 · 核心原则 (每次拍摄前默读)

| 原则 | 落地要求 |
|---|---|
| 真诚 | 允许路人说 no · 允许皱眉 · 允许 Freddy 说"this might not be for everyone" |
| 温度 | Freddy 参考 Mr. Rogers / 童年糖果店爷爷 / Graza 创始人 · 禁毒舌冷硬 |
| 玩起来 | 不做影棚桌面糖果 · 户外 + Freddy 真人 + 路人 > 桌面字幕 |
| HKRR | 快乐 / 知识 / 共鸣 / 节奏 · 每条视频秒级 beat 命中 |
| 无 Mexico | 绝禁 Mexican / Latino / Latin / Mexico 标签和视觉元素 |

**Freddy 3 层固化 (C-01 / C-03 必须)**
- 开场 0-2s · 招牌微笑 + 举糖手势 + "so today I got something to show you"
- 中段 25-30s · 递糖动作 + "let's see what they think"
- 收尾 -5s · 点头微笑 + "catch you tomorrow" 或 "see you at the shop"
