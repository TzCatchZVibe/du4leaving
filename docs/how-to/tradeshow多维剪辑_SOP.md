# Trade Show 多维剪辑 SOP

> v1.0 · 2026-04-22
> 目标: 一场 trade show 一天拍摄 → 回来后一套素材分 3-4 种剪法 · 最大化 ROI
> 适用账号: @happyglobalschoice (Choice) · @happyglobalsnacks (Snacks) · @us_happyglobal / @happyglobal_inc (HG PR) · @pulseon.energy.drink / @pulseon_energy_drink (PulseOn PR · 如参展)

---

## 核心原则 · 为什么要多维剪辑

**一天 trade show 素材 ≈ 4-8 小时原片 · 如果只剪 1 条 60s 视频是浪费 95% 素材。**

同一场 booth,不同剪法喂不同账号:
- **Choice 街采版** → C-03 活动采访 60s · 带货 · TK Shop tag · 下单转化 KPI
- **HG PR 品牌版** → O-04 Teaser/Recap 30-45s · 品牌故事 · 双号同步 · Save/DM KPI
- **PulseOn PR 品牌版** (如 PulseOn 参展) → O-04 PulseOn caption · 偏能量饮料场景
- **Snacks ASMR 版** → C-09 特写咀嚼 15s · 高完播 · 粉丝圈层扩散

**4 种剪法 · 1 套素材 · 4x 内容产出 · 产出比 4:1**

## 拍摄日分工 (TZ / Frida / Hank 3 人版)

**镜头前任务**:
- [ ] 4-6 次街采采访主持 (C-03 素材)
- [ ] 2-3 次 HG 品牌 Why 口播 (O-04 · O-09 素材 · 团队面孔 1)
- [ ] 1 次 booth tour 全景口播 (O-04)
- [ ] 1 次展后 recap 真实感受口播 (O-09 情绪段)

**镜头后任务**:
- [ ] 每 2 小时 review 一次已拍素材 · 快速筛 A/B/C 级
- [ ] 决定今晚回去剪哪条优先
- [ ] 和 Ranny/Shay 预审同步
- [ ] 记录金句 timecode 给剪辑省时间

**设备**:
- 手机 (竖拍 · 自拍视角 · 真实感)
- 领夹 mic (采访用)

---

**主摄任务**:

- [ ] booth 全景 · 人流 · 产品墙 (15%)
- [ ] 团队合影 · 握手 · 买手来访 (10%)
- [ ] 现场精彩瞬间机动抓拍 (15%)

**导演任务**:
- [ ] 每条街采前和 TZ 对 hook 句
- [ ] 控制 C-03 结构 · 不少于 5 个路人反应
- [ ] 抓一个 A+ 级金句反应 (整场最有用那 1 秒)

**镜头前任务** (少量):
- [ ] 1 次 HG PR 团队出镜 (女性视角 · 展位幕后的 1 分钟)

**设备**:
- 主相机 (Sony A7 / Canon · 短焦头)
- 稳定器
- 收音备份

---

### Hank · B 机位 + ASMR + 剪辑预处理 (95% 镜头后)

**B 机位任务**:
- [ ] 产品/手部特写 · 递糖/拆包装/入口 (C-09 ASMR 素材主力)
- [ ] 反应镜头补位 · 路人表情 close-up (C-03 多路人堆叠用)
- [ ] PulseOn 开罐 · 倒入玻璃杯 · 冰块入杯 (如 PulseOn 参展 · C-09 + O-04 PulseOn)
- [ ] Booth 细节 · logo/装饰/产品排列的美图 (O-04 品牌锁)
- [ ] Team 幕后 · 布展/收展/休息/吃饭 (O-04 · O-09)

**ASMR 采音**:
- [ ] 所有特写镜头独立收音 · 关闭环境声
- [ ] 产品拆包/咬/咀嚼/倒饮料 · 每种 2-3 次备份

**现场剪辑预处理**:
- [ ] 每 1-2 小时整理素材到 Lark · 按类型分文件夹
- [ ] 标记 A/B/C 级 (TZ 协助)
- [ ] 晚上回去立即导进 CapCut/Final Cut

**设备**:
- B 机位相机 (微单 · 定焦头 35mm / 50mm)
- 全向麦克风 (ASMR 专用)
- 存储卡若干

## 镜头清单 · Boolean Checklist

**拍摄期每小时 check 一次 · 少哪类镜头就优先补**

### Choice 街采版 (C-03) · 60 秒 · 必须项

- [ ] Hook · Booth 能量全景 3s (micro)
- [ ] 博主 booth 前定位口播 5s (short)
- [ ] 路人 1 · 凑过来递糖全过程 · 拆包/入口/第一反应 10-12s
- [ ] 路人 2-3 · 快剪反应 2-3s each (至少 2 个)
- [ ] 产品特写 + booth logo 同屏 3s (mini-hook)
- [ ] 路人 4-5 · 朋友一起吃 / 多人分享 6-10s
- [ ] A+ 金句 reaction · 整场最夸张那位 10-12s
- [ ] 评分/大笑收尾 3-5s
- [ ] 双 CTA 画面 · 产品 + booth 号 + shop tag 4-5s
- [ ] **Total 需至少 5-7 个独立路人出镜**

### HG PR 品牌版 (O-04) · 30-45 秒 · 必须项

- [ ] Hook · 事件定位大字 (event name + booth # + 城市) 2-3s
- [ ] 团队面孔口播 · TZ 或 Ranny 或 Shay · 『We are HG at [event]』4-6s
- [ ] 布展/人流 beat · 搬箱子 or 队伍排长 5-8s
- [ ] 买手/客户握手 or 路人第一次尝 reaction 2-3 段
- [ ] 产品 + event logo 双露 3-5s mid-hook
- [ ] 团队真实感受 · 疲惫/激动/兴奋 · 手机自拍视角 8-12s (oxytocin 锚点)
- [ ] 双 CTA · 『Come say hi』+『DM for samples』4-6s
- [ ] **与 Choice 版的差异: 必须有 1 个团队成员情绪真露 · 不是表演**

### PulseOn PR 品牌版 (O-04 PulseOn) · 30-45 秒 · 仅当 PulseOn 参展

- [ ] Hook · PulseOn × event × 城市大字 2-3s
- [ ] PulseOn booth 全景或开罐特写 3-5s
- [ ] 运动/电竞/工作场景的路人 (不是 candy 路人) 2-3 段
- [ ] 『Plant-based caffeine · Asian-owned』 一句话定位 4-6s
- [ ] PulseOn 罐 × 闪电 Z logo mid-hook 3-5s
- [ ] Ambassador or 团队关于 PulseOn 的一句感受 8-12s
- [ ] CTA · 『DM for samples』+ 闪电 Z end card 4-6s
- [ ] **与 HG PR 的差异: 场景必须偏 workout/gaming/studio · 不是candy 氛围**

### Snacks ASMR 版 (C-09) · 15 秒 · 机动拍

- [ ] 产品拆包特写 + 拆袋声 3-5s
- [ ] 入口特写 + 咀嚼声 3-5s
- [ ] 糖拉丝/碎裂/流动慢镜头 2-4s
- [ ] 产品包装 hero shot + 品牌 logo 2-3s
- [ ] **独立 mic 采音 · 环境噪音 < -35dB**

## 回工作室后剪辑优先级

**发布节奏 3 天窗口 · 按此优先级排:**

### Day 0 晚 (拍摄日回到工作室)
1. **Hank 当晚**: 素材按类型分文件夹入 Lark · A/B/C 级标注 · 导进 CapCut project
2. **TZ 当晚 30 分钟**: 抓 24h 内要发的 1 条 BTS story (手机原片直发 · 不剪) · 放到 HG PR IG Story
3. 其他人下班

**为什么**: IG Story 24h 窗口 · 展会能量最新鲜的那一天必发 · 不做精细剪辑

### Day 1
1. **早上 Hank**: 优先剪 **Choice 街采版 C-03** · 带货 ROI 最高 · 3-4 小时产出
2. **下午 Frida**: 同步剪 **HG PR 品牌版 O-04 Recap** · 品牌叙事 · 3-4 小时产出 (素材复用 C-03 的 20%)
3. **晚上 TZ**: 审两条成品 · 提修改意见 · 打包交 Ranny/Shay 审

**为什么**: Choice 先出是因为带货窗口紧 (72h trade show 热度递减) · HG PR 可缓一天但 3 天内必出

### Day 2
1. **早上**: Ranny/Shay 审核反馈 → Hank/Frida 修改
2. **中午**: 发布 Choice C-03 · TK Shop tag · HG seller 后台 boost
3. **下午 Hank**: 剪 **PulseOn PR 品牌版** (如 PulseOn 参展) · 复用部分 O-04 素材 + PulseOn 专属镜头
4. **晚上**: Hank 剪 **Snacks C-09 ASMR** · 最简单 · 1-2 小时完成

### Day 3
1. **早上**: 审 PulseOn PR + Snacks ASMR 2 条 → 修 → 过审
2. **中午**: 发 HG PR Recap (TK + IG 双发 · IG 版独立剪)
3. **晚上**: 发 PulseOn PR (如有) + Snacks ASMR

### Day 4-5 (buffer)
- 机动修改/补发
- 如果展会多日 · 可追加 Day 2/3 on-site 素材

## 交审核时间轴

```
Day 0 晚    拍摄日
            └─> IG Story BTS 24h 自由发 (不需审)

Day 1       剪辑主力日
            下午 5pm: Choice C-03 + HG PR O-04 初剪 → 交审

Day 2       审核 + 发布 Choice
            早 9am: Ranny/Shay 审核反馈
            中午 12pm: Hank 改完
            下午 2pm: Choice C-03 发布
            晚 5pm: PulseOn PR + Snacks C-09 初剪 → 交审

Day 3       审核 + 发布 PR 系
            早 9am: Ranny/Shay 审核 PR 系
            中午 12pm: 修改完
            下午 2pm: HG PR O-04 Recap TK + IG 发布
            晚 7pm: PulseOn PR + Snacks ASMR 发布

Day 4-5     Buffer · 机动修改
```

**关键规则**:
- 审核只审成品 · 不审方向 (本 SOP + PR 规划 v1.0 为方向说明)
- 每次交审必附: `成品视频 + caption (TK + IG 两版) + hashtag 清单 + 发布时间`
- 审核意见 1 轮往返 · 超过 1 轮升级到 TZ 协调

## 踩坑 checklist · 避免浪费素材

- [ ] 每个街采路人至少拍 A+B 双机位 · 不然剪不出 mid-hook
- [ ] TZ 的 HG PR 情绪段必须手机自拍 · 不要用主相机 (太假)
- [ ] ASMR 镜头必须独立 mic · 不要靠主相机板载 mic (噪音盖过)
- [ ] Booth logo + event logo 同框镜头每小时拍 1 次 · 不同角度备份
- [ ] 团队合影每天至少拍 2 次 · 上午 + 下午 · 能量不一样
- [ ] 所有人签 release 表 · 即使是展会公共区域 (B2B 买手尤其要签)
- [ ] PulseOn 参展时 · B 机位必须拍开罐 + 冰块入杯的 3 种不同变体
- [ ] 如果临展时间紧 · 优先保 C-03 (带货) + O-04 (品牌) · ASMR 可放后面补
